# Percentile Rank (PR) จากคะแนนเกรดเฉลี่ย (GPA)

เอกสารนี้อธิบายความหมายของ **Percentile Rank (PR)** วิธีคำนวณจากคะแนน GPA
และการจัดการกรณีที่นักเรียนได้คะแนนเท่ากัน โดยใช้แนวคิด **Midrank / Average Rank**
ตามสูตรที่นำเสนอใน OpenStax

------------------------------------------------------------------------

## 1. Percentile Rank คืออะไร

**Percentile Rank (PR)** คือค่าที่แสดงตำแหน่งสัมพัทธ์ของคะแนนหนึ่ง
เมื่อเปรียบเทียบกับคะแนนทั้งหมดในกลุ่ม โดยแสดงเป็นร้อยละ

ตัวอย่างเช่น PR = 67.5 หมายความว่า คะแนนนั้นอยู่ ณ ตำแหน่งเปอร์เซ็นไทล์ประมาณ 67.5
เมื่อเทียบกับกลุ่มข้อมูลตามวิธีคำนวณที่เลือก

> PR เป็นการบอกตำแหน่งเมื่อเทียบกับกลุ่ม ไม่ใช่ร้อยละของคะแนน GPA ที่นักเรียนได้รับ

## 2. สูตรคำนวณ Percentile Rank เมื่อมีคะแนนซ้ำ

กรณีมีคะแนนซ้ำ ควรระบุวิธีจัดการคะแนนที่เท่ากันให้ชัดเจน วิธีหนึ่งคือใช้สูตร Midrank
ซึ่งให้คะแนนที่เท่ากันมีค่า PR เท่ากัน

\[ PR = `\frac{x + 0.5y}{N}`{=tex}`\times 100`{=tex} \]

โดยที่

-   (PR) = Percentile Rank ของคะแนนที่ต้องการหา
-   \(x\) = จำนวนคะแนนที่ **น้อยกว่า** คะแนนเป้าหมาย
-   \(y\) = จำนวนคะแนนที่ **เท่ากับ** คะแนนเป้าหมาย
-   \(N\) = จำนวนข้อมูลทั้งหมด

### ตัวอย่าง

สมมติว่ามีนักเรียน 20 คน และมีข้อมูลดังนี้

-   มีนักเรียน 12 คนได้ GPA ต่ำกว่า 3.50
-   มีนักเรียน 3 คนได้ GPA เท่ากับ 3.50
-   มีนักเรียน 5 คนได้ GPA สูงกว่า 3.50

แทนค่าในสูตร

\[ PR = `\frac{12 + 0.5(3)}{20}`{=tex}`\times 100`{=tex} \]

\[ PR = `\frac{13.5}{20}`{=tex}`\times 100`{=tex} = 67.5 \]

ดังนั้น นักเรียนทั้ง 3 คนที่ได้ GPA = 3.50 จะมี Percentile Rank เท่ากัน คือ **67.5**

### เหตุใดคะแนนที่เท่ากันจึงได้ PR เท่ากัน

คะแนนที่เท่ากันถือว่าอยู่ในกลุ่มคะแนนเดียวกัน จึงใช้จำนวนคะแนนที่ต่ำกว่า ((x))
และจำนวนคะแนนที่เท่ากัน ((y)) ชุดเดียวกันในการคำนวณ ทำให้ได้ค่า PR เท่ากัน
ไม่ควรให้ผู้ที่ได้ GPA เท่ากันมี PR ต่างกันเพียงเพราะเรียงลำดับแถวในตาราง

## 4. สูตร Excel

สมมติว่าข้อมูล GPA อยู่ในช่วง `A2:A21` และต้องการคำนวณ PR ของข้อมูลในแถวที่ 2
ให้ใส่สูตรต่อไปนี้ในเซลล์ PR

``` excel
=(COUNTIF($A$2:$A$21,"<"&A2)+0.5*COUNTIF($A$2:$A$21,A2))/COUNT($A$2:$A$21)*100
```

จากนั้นคัดลอกสูตรลงไปจนครบทุกแถว

สูตรนี้ทำงานดังนี้

1.  `COUNTIF($A$2:$A$21,"<"&A2)` นับจำนวน GPA ที่ต่ำกว่าค่าใน A2
2.  `COUNTIF($A$2:$A$21,A2)` นับจำนวน GPA ที่เท่ากับค่าใน A2
3.  คูณจำนวนคะแนนที่เท่ากันด้วย 0.5 เพื่อใช้ตำแหน่งกึ่งกลางของกลุ่มคะแนนซ้ำ
4.  หารด้วยจำนวนข้อมูลทั้งหมด แล้วคูณ 100 เพื่อแสดงเป็นสเกล 0--100

หากต้องการให้ผลลัพธ์เป็นสัดส่วนระหว่าง 0 ถึง 1 และใช้รูปแบบ Percentage ของ Excel
ให้ตัด `*100` ท้ายสูตรออก

``` excel
=(COUNTIF($A$2:$A$21,"<"&A2)+0.5*COUNTIF($A$2:$A$21,A2))/COUNT($A$2:$A$21)
```

## 5. Percentile Rank ต่างจาก Percentile อย่างไร

คำสองคำนี้เกี่ยวข้องกัน แต่ตอบคนละคำถาม

  -------------------------------------------------------------------------------
  คำศัพท์                   คำถามที่ต้องการตอบ         ความหมาย
  ----------------------- ----------------------- -------------------------------
  Percentile Rank (PR)    คะแนนที่ได้อยู่ ณ            เริ่มจากคะแนนที่มี
                          ตำแหน่งเปอร์เซ็นไทล์ใด      แล้วคำนวณตำแหน่งสัมพัทธ์ของคะแนนนั้น

  Percentile (เช่น P75)    คะแนน ณ เปอร์เซ็นไทล์ที่ 75  เริ่มจากเปอร์เซ็นไทล์ที่ต้องการ
                          คือเท่าไร                 แล้วหาค่าคะแนน ณ ตำแหน่งนั้น
  -------------------------------------------------------------------------------

ตัวอย่าง

-   **Percentile Rank:** นักเรียนได้ GPA 3.50 แล้วต้องการทราบว่า GPA นี้อยู่ ณ
    ตำแหน่งเปอร์เซ็นไทล์ใดในกลุ่ม
-   **Percentile:** ต้องการทราบว่า GPA ที่เป็นจุดตัดของเปอร์เซ็นไทล์ที่ 75 มีค่าเท่าไร

OpenStax อธิบายการหาตำแหน่งเปอร์เซ็นไทล์ของข้อมูลเรียงลำดับด้วยสูตร

\[ i = `\frac{k}{100}`{=tex}(n+1) \]

โดยที่

-   \(i\) = ตำแหน่งของข้อมูลที่ต้องการหา
-   \(k\) = เปอร์เซ็นไทล์ที่ต้องการ เช่น 75
-   \(n\) = จำนวนข้อมูลทั้งหมด

สูตรนี้เป็นการหาตำแหน่งของ **Percentile** ไม่ใช่สูตรเดียวกับการคำนวณ **Percentile
Rank** ของคะแนนที่ทราบค่าแล้ว

## 6. เปรียบเทียบวิธีคำนวณใน Excel

Excel มีฟังก์ชันที่เกี่ยวข้อง ได้แก่

-   `PERCENTRANK.INC(array, x)` --- คำนวณอันดับเปอร์เซ็นไทล์โดยใช้แนวทาง
    Inclusive
-   `PERCENTRANK.EXC(array, x)` --- คำนวณอันดับเปอร์เซ็นไทล์โดยใช้แนวทาง
    Exclusive

ทั้งสองฟังก์ชันอาจให้ผลต่างจากสูตร Midrank ที่ใช้ในเอกสารนี้
เนื่องจากนิยามและวิธีจัดการตำแหน่งปลายช่วงแตกต่างกัน

**ข้อเสนอแนะ:** หากนำ PR ไปใช้รายงานผลการเรียนหรือเปรียบเทียบตำแหน่ง GPA
ภายในกลุ่ม ควรกำหนดวิธีคำนวณให้ชัดเจน ใช้วิธีเดียวกันกับนักเรียนทุกคน
และระบุสูตรไว้ในเอกสารประกอบ เพื่อให้ตรวจสอบและทำซ้ำผลได้

ไม่ควรนำค่าจาก `PERCENTRANK.INC`, `PERCENTRANK.EXC` และสูตร Midrank
มาใช้ปะปนกันในรายงานชุดเดียวโดยไม่อธิบายความแตกต่าง

## 7. ข้อควรระวังในการนำไปใช้กับ GPA

1.  **PR เป็นค่าที่สัมพันธ์กับกลุ่มอ้างอิง** หากเปลี่ยนกลุ่มนักเรียนหรือปีการศึกษา ค่า PR ของ
    GPA เดิมอาจเปลี่ยนไป
2.  **คะแนนซ้ำต้องจัดการอย่างสม่ำเสมอ** สูตร Midrank ทำให้ผู้ที่ได้ GPA เท่ากันมี PR
    เท่ากัน
3.  **PR ไม่ใช่เกรดหรือร้อยละผลสัมฤทธิ์** PR = 80 ไม่ได้หมายความว่านักเรียนได้ GPA
    80% แต่หมายถึงตำแหน่งสัมพัทธ์ตามวิธีคำนวณที่กำหนด
4.  **ควรระบุกลุ่มข้อมูล** เช่น นักเรียนระดับชั้นเดียวกัน รุ่นเดียวกัน หรือกลุ่มสาขาเดียวกัน
    เพื่อให้ความหมายของ PR ชัดเจน
5.  **ควรระบุวิธีคำนวณ** โดยเฉพาะเมื่อใช้เปรียบเทียบผลระหว่างปีหรือระหว่างกลุ่ม
